# 📦 NextStock

**NextStock** is a smart inventory management and demand forecasting system designed to help businesses efficiently track products, manage stock, monitor sales, and predict future inventory requirements.

## 🚀 Features

* 📦 Product & Inventory Management
* 🏷️ Category Management
* 🚚 Supplier Management
* 📊 Sales Tracking
* 🛒 Purchase Order Management
* 📉 Demand Forecasting
* 🔔 Low Stock & Reorder Recommendations
* 📈 Dashboard & Analytics
* 📱 QR Code / Barcode Generation & Scanning
* 🔐 User Authentication & Role Management

## 🛠️ Tech Stack

### Backend

* Java
* Spring Boot
* Spring Data JPA
* Spring Security
* REST APIs
* Maven

### Frontend

* React.js
* JavaScript
* HTML
* CSS

### Database

* MySQL

### Forecasting

* Moving Average
* Weighted Moving Average

## 📁 Project Architecture

`React Frontend → Spring Boot REST API → MySQL Database`

The forecasting module uses historical sales data to estimate future product demand and assist with inventory planning.

## 🔮 Planned Functionality

NextStock will analyze historical sales, forecast product demand, recommend reorder quantities, identify low-stock products, and provide inventory insights through an interactive dashboard.
